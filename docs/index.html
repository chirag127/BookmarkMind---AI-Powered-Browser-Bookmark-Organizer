BookmarkMind

AI-powered Chrome extension that auto-organizes your bookmarks into intelligent, functional folders using any OpenAI-compatible LLM. Bring your own key.

View on GitHub Install

13 built-in providers

Groq, Cerebras, Gemini, OpenRouter, Mistral, HuggingFace, DeepSeek, OpenAI, Novita + localhost (LM Studio, Ollama, LiteLLM, OmniRoute).

Bring your own key

Add any OpenAI-compatible HTTPS endpoint. AES-256-GCM encrypted key storage in chrome.storage.sync.

FMHY-style folders

Categorizes by what services DO — "Tools > File Tools > Cloud Storage" — not by vendor.

Zero telemetry

No server, no analytics, no phone-home. Manifest V3, fully client-side.

Install from source

  1. git clone https://github.com/chirag127/bookmark-mind.git
  2. Open Chrome → chrome://extensions/ → enable Developer mode
  3. Click Load unpacked → select the extension/ directory
  4. Click the toolbar icon to open the popup and add a provider key
